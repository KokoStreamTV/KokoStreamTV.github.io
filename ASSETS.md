# Asset sources

- `assets/collection.svg` is an original illustration for this website. The fictional movie, album, and book
  artwork illustrates a personal media collection; it is not a screenshot of Koko. It is covered by the
  website's AGPL-3.0-only license.
- `assets/koko.svg` and `assets/koko.png` come from
  [Koko's assets directory](https://github.com/KokoStreamTV/Koko/tree/814f96a7c6802c85a9d8a469e8f4668e74ec5da9/assets).
  They retain the project's existing terms, included at [LICENSES/LizardByte-Source-Available.txt](LICENSES/LizardByte-Source-Available.txt).
- `assets/lizardbyte.svg` comes from
  [LizardByte's branding directory](https://github.com/LizardByte/.github/tree/master/branding/logos).
  The LizardByte logo was created by GitHub user [BenDev9](https://github.com/BenDev9).
- Manrope is bundled locally from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope).
  Its SIL Open Font License is included at `assets/fonts/OFL-Manrope.txt`.

Product and organization names and logos identify their respective projects. The website's AGPL license does
not replace the existing asset or font terms, or Koko's application license.
